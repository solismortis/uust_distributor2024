Для запуска сервера рекомендуется установить PyCharm Community Edition последней версии.

Далее в терминале необходимо запустить "pip install -r requirements.txt" для установки всех библиотек нужных версий.

Затем можно запускать server.py.
После запуска, нужно открыть браузер и перейти на сайт по адресу: "http://127.0.0.1:5000/menu".
Из страницы можно перейти к поиску позиций по ID, или выбрать конкурсные группы и выбрать список с абитуриентами
подавшими оригиналы документов или список со всеми абитуриентами.
