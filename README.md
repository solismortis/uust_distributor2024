Распределятор абитуриентов по приоритетам УУНИТ 2024.

Снижает уровень безумия при поступлении, вызванного размножением абитуриентов по спискам, 
вызванного использованием приоритетов.

Открыть в Colab (заброшено): https://colab.research.google.com/github/solismortis/uust_distributor2024/blob/master/main.ipynb.

В папке data_back_up хранятся сохраненные с сайта УУНИТ в разные дни html.

В папке html files лежат используемые на данные момент html.

main.ipynb использовался для Colab.

Описание работы алго:
1) На вход подаются html по бакалавриату и специалитету с сайта УУНИТ и id абитуриента
2) Парсинг данных из html в dict, полный padnas.dataframe по каждой конкурсной группе (с удалением коммерции)
3) Создается dict с ключами-абитами, значениями-приоритетами этого абита
4) Поиск конкурсных групп абита на входе и его баллов
5) Сортировка. Делаем while loop по всем таблицам; в каждой выбираем всех вмещающихся абитов,
    смотрим их прио, если все прио перед этим прио сгорели (здесь под "сгорел" понимается вылет из конкурсной группы ввиду
    отсутствия мест), то зачисляем; убираем абита из остальных таблиц; если таблица обработана, выкидываем ее в
    sorted_groups
